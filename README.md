# Zlobin Music

Сайт гитариста и преподавателя Никиты Злобина. Будущий домен: **zlobinmusic.ru**.

Текущий этап: сайт знакомства с будущими курсами и обращения к преподавателю. Программы предварительные; цены, даты, оплата и личный кабинет не объявлены.

## Устройство

- `index.html`, `styles.css`, `app.js` — исходники без зависимостей и сборочного фреймворка.
- `assets/` — реальные фотографии Никиты, авторский SVG логотип, локальный Golos Text (лицензия OFL).
- `scripts/build.mjs` — собирает только публичные файлы в `docs/`.
- `docs/` — источник GitHub Pages: ветка `main`, каталог `/docs`.
- Прежние концепции остаются локально и не публикуются.

Проверка и сборка: `node --check app.js` и `node scripts/build.mjs`.
Локальное превью: `python3 -m http.server 8768 --bind 127.0.0.1`.

## Поведение

Программы курсов открываются в доступном диалоге. Выбор задачи предлагает направление. Текст обращения можно изменить и скопировать; отправка выполняется самим посетителем на странице Никиты во ВКонтакте. Сайт не собирает и не хранит заявки. Telegram-ссылка открывает канал, а не личный чат.

Учебный пример использует синтез Web Audio только после нажатия. Четыре голоса: Dm7 [50,57,60,65], G7/D [50,55,59,65], Cmaj7 [48,55,59,64]. Стандартный строй; верхний голос F4–F4–E4. Это не исполнение Никиты. При остановке звук плавно затухает; при скрытии страницы воспроизведение прекращается.

## Перед открытием продаж

Никита подтверждает программы, формат, стоимость, сроки, обратную связь и доступ к материалам. После этого подключается реальная платёжная ссылка/платформа и проверяется полный путь покупки. До подключения домена CNAME не создаётся. Предпросмотр закрыт от поисковой индексации; это не ограничение доступа.
